# Legal NLP: IPC Section Prediction and Evidence Retrieval

## Overview
An NLP-based legal case analysis system that predicts relevant Indian Penal Code (IPC) sections from case facts and retrieves supporting evidence sentences from a legal case database.

The system combines Sentence Transformers, semantic embeddings, multi-label classification, and evidence retrieval through an interactive Gradio interface.

## Key Features
- Legal case text analysis
- Sentence Transformer-based embeddings
- Multi-label IPC section prediction
- Supporting evidence sentence retrieval
- Prediction confidence visualisation
- Interactive Gradio web interface

## Technology Stack
- Python
- Sentence Transformers
- PyTorch
- Scikit-learn
- Pandas
- NumPy
- Gradio

## Workflow
1. Dataset loading and preprocessing
2. Semantic embedding generation
3. Multi-label classifier training
4. Model evaluation
5. Model saving
6. Evidence retrieval
7. Gradio interface deployment

## Evaluation
Evaluation metrics include accuracy, precision, recall, and F1-score.

## How to Run
1. Open the notebook in Google Colab.
2. Install the required dependencies.
3. Load the legal case dataset.
4. Execute the notebook cells sequentially.
5. Launch the Gradio interface.

## Disclaimer
This project is intended for academic and research purposes. Predictions should not be considered professional legal advice.
